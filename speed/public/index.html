      How this works. The page never sees an API key. Our server calls POST https://api.decisionmodels.io/v1/systemone with model s1-fast and one choice question, the same request format Jev uses ("Jev-compatible"). The live budget is shared by all visitors and capped below the account limit; when it is used up you see a replay of the most recent live run, and the page says so.

      The chat is synthetic, written for this demo; the "intended" labels are the author's, not a benchmark. Jev is a model by TypeSafe; Jev numbers on this page are our own recorded measurements with the date shown. This chat is easy for both models. On the harder public JevBench items (our run on 17 Oct 2026, 297 items) s1-fast picks the right answer 80.5 % of the time against Jev 1.14.0's 86.9 %. s1-fast trades accuracy for speed; for harder decisions, s1-pro scores 89.9 % on the same items.
